Série 1 — Bases Python

Q1. À quoi sert print() ?

  • A) Créer une variable
  • B) Afficher un message
  • C) Tester une condition
  • D) Créer une boucle
✅ Réponse : B
print() permet d'afficher un message ou une valeur à l'écran.

Série 2 — Opérateurs

Q1. Quelle est la sortie ?

print(10 / 2)
  • A) 5
  • B) 5.0
  • C) 10
  • D) Erreur
✅ Réponse : B
En Python, / retourne toujours un nombre décimal (float).

Série 3 — Conditions

Q1. Que va afficher ce code ?

x = 3
if x > 5:
    print("A")
else:
    print("B")
✅ Réponse : B
La condition x > 5 est fausse (3 n'est pas > 5), donc le bloc else s'exécute.

Série 4 — Boucles

Q1. Que va afficher ce code ?

for i in range(3):
    print(i)
✅ Réponse attendue : 0 1 2
range(3) génère les entiers 0, 1 et 2.

Exercices fondamentaux

Somme de deux nombres

Énoncé : Lire deux nombres, calculer et afficher leur somme.

Voir la correction 
nb1 = int(input("Saisir le premier nombre : "))
nb2 = int(input("Saisir le deuxième nombre : "))
somme = nb1 + nb2
print("La somme =", somme)

Explication : input() lit un texte, int() convertit en entier, puis on additionne avec +.

Factorielle

Énoncé : Lire un entier positif ou nul et calculer sa factorielle. Refuser les négatifs.

Voir la correction 
n = int(input("Entrez un nombre entier positif : "))
 
if n >= 0:
    factorielle = 1
    for i in range(1, n + 1):
        factorielle *= i
    print(f"La factorielle de {n} est {factorielle}")
else:
    print("Le nombre saisi est négatif.")

Explication : La factorielle de n = 1×2×…×n. On multiplie progressivement dans une boucle for.

Palindrome

Énoncé : Demander un mot et déterminer s'il est un palindrome (ex : ressasser).

Voir la correction 
mot = input("Entrez un mot : ")
if mot == mot[::-1]:
    print("Le mot est un palindrome.")
else:
    print("Le mot n'est pas un palindrome.")

Explication : mot[::-1] inverse le mot. Si le mot = son inverse, c'est un palindrome.

Boucles, calculs et logique

Somme et moyenne des n premiers entiers

Énoncé : Calculer la somme des n premiers entiers naturels, puis leur moyenne.

Voir la correction 
n = int(input("Entrez un nombre entier positif : "))
while n < 1:
    n = int(input("Entrez un nombre entier positif : "))
 
somme = 0
for i in range(1, n + 1):
    somme += i
 
moyenne = somme / n
print("La somme des", n, "premiers entiers est", somme)
print("Leur moyenne est", moyenne)

Explication : On force n à être positif avec while. Puis on additionne de 1 à n et on divise par n.

Produit par additions successives

Énoncé : Lire deux entiers positifs A et B. Calculer A×B comme A+A+…+A (B fois).

Voir la correction 
a = int(input("Entrez un premier entier positif : "))
while a < 0:
    a = int(input("Entrez un premier entier positif : "))
 
b = int(input("Entrez un deuxième entier positif : "))
while b < 0:
    b = int(input("Entrez un deuxième entier positif : "))
 
produit = 0
for i in range(b):
    produit += a
 
print("Le produit de", a, "et", b, "est", produit)

Explication : Multiplier = additionner le même nombre plusieurs fois. On ajoute a, b fois.

Conversion décimal → binaire

Énoncé : Lire un nombre décimal et afficher son équivalent binaire.

Voir la correction 
dec = int(input("Entrez un nombre décimal : "))
binaire = ""
 
while dec > 0:
    binaire = str(dec % 2) + binaire
    dec //= 2
 
print("Le nombre en binaire est :", binaire)

Explication : On divise par 2 et on garde les restes (0 ou 1). En les lisant dans l'ordre inverse, on obtient le binaire.

12 nombres réels : moyenne, variance, écart-type

Énoncé : Lire 12 nombres réels et calculer la moyenne, la variance et l'écart-type.

Voir la correction 
import math
 
nombres = []
for i in range(12):
    nombre = float(input("Entrez un nombre réel : "))
    nombres.append(nombre)
 
moyenne = sum(nombres) / len(nombres)
variance = sum((x - moyenne) ** 2 for x in nombres) / len(nombres)
ecart_type = math.sqrt(variance)
 
print("Moyenne :", moyenne)
print("Variance :", variance)
print("Écart-type :", ecart_type)

Explication : Moyenne = somme/12. Variance = moyenne des (x−moyenne)². Écart-type = racine de la variance.

Mini-projet : Analyse d'un champ de cacao

Champ de cacao 1 — Types de données et affichage

Énoncé : Initialiser les variables du champ et les afficher (une info par ligne).

Voir la correction 
nom_champ = "CacaoBon"
surface = 10.5
nombre_arbres = 1200
rendement = 2.4
 
print("Nom du champ :", nom_champ)
print("Surface :", surface, "hectares")
print("Nombre d'arbres :", nombre_arbres)
print("Rendement moyen par arbre :", rendement, "kg")

Explication : Types : texte (str), décimal (float), entier (int). On affiche avec print().

Champ de cacao 2 — Entrée utilisateur et rendement total

Énoncé : Demander le nombre d'arbres et le rendement moyen, calculer le rendement total.

Voir la correction 
arbres = int(input("Entrez le nombre d'arbres : "))
rendement = float(input("Entrez le rendement moyen par arbre (en kg) : "))
 
total = arbres * rendement
print("Le rendement total du champ est de", total, "kg.")

Explication : Rendement total = arbres × rendement.

Champ de cacao 3 — Rendement satisfaisant / moyen / insuffisant

Énoncé : Comparer le rendement calculé avec l'attendu : satisfaisant (≥), moyen (80%-99%), insuffisant (<80%).

Voir la correction 
attendu = float(input("Entrez le rendement total attendu (en kg) : "))
 
if total >= attendu:
    print("Le rendement est satisfaisant.")
elif total >= 0.8 * attendu:
    print("Le rendement est moyen.")
else:
    print("Le rendement est insuffisant.")

Explication : 80% de l'attendu = 0.8 * attendu. On utilise if / elif / else.

Champ de cacao 4 — Densité d'arbres par hectare

Énoncé : Calculer la densité (arbres/hectare) et comparer à la densité optimale de 120.

Voir la correction 
surface = float(input("Entrez la surface du champ (en hectares) : "))
arbres = int(input("Entrez le nombre d'arbres : "))
 
densite = arbres / surface
print("La densité d'arbres est de", densite, "arbres/hectare.")
 
densite_opt = 120
if densite == densite_opt:
    print("La densité est optimale.")
elif densite > densite_opt:
    print("La densité est trop dense.")
else:
    print("La densité est trop faible.")

Explication : Densité = arbres / surface. On compare ensuite à la densité optimale de 120 arbres/ha.
